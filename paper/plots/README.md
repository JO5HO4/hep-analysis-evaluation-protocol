# Paper plots

This is the canonical location for figures used in paper drafts. Each task has
its own subdirectory, and every plot is saved as both SVG (editable vector
artwork) and PNG (raster artwork suitable for slides and manuscript drafts).

## Current contents

- `top-reconstruction/` — figures generated from the selected 15-run manual
  evaluation matrix, directly documented workflow activities/stages, and
  compatible frozen mass-greedy baseline comparisons.

The figure generators remain adjacent to their task review records so their
input evidence and generation logic are easy to audit. A plot is descriptive
manual-review evidence, not a Harbor reward or authoritative outcome grade.
