# Four-lepton (H → ZZ* → 4l) counting experiment analysis

## Method

The input is a set of independent Poisson-counting channels, each with an
observed count, a background-only expectation, and a Standard-Model signal
expectation. The analysis (`analysis.py`) performs:

1. **Likelihoods.** For each channel `i`, the Poisson log-likelihood is
   `logPoisson(k_i, lambda_i) = -lambda_i + k_i*log(lambda_i) - log(k_i!)`
   (computed with `scipy.stats.poisson.logpmf` for numerical stability).
   The total background-only log-likelihood `logL_b` uses `lambda_i =
   background_i`; the signal-plus-background log-likelihood `logL_sb` uses
   `lambda_i = signal_i + background_i`. Both are summed over channels.

2. **Test statistic.** `q = -2*(logL_sb - logL_b)`, i.e. minus twice the log
   likelihood ratio of the signal+background to background-only hypotheses
   (a LEP-style `-2 ln Q` statistic). More negative values of `q` indicate
   data that looks more signal-like.

3. **Significance.** Background-only pseudo-experiments are generated by
   drawing Poisson toy counts from the background expectation in each
   channel (5,000,000 toys by default, vectorized with NumPy). The test
   statistic `q` is computed for every toy in the same way as for the
   observed data. The background-only p-value is the fraction of toys with
   `q_toy <= q_obs` (at least as signal-like as observed). This p-value is
   converted to a one-sided Gaussian significance via `Z =
   Phi^-1(1 - p) = norm.isf(p)`. The result is compared against the
   conventional 3-sigma "evidence" threshold.

4. **Signal-strength fit.** A signal-strength parameter `mu` scales the
   signal expectation, so channel `i` has mean `mu*signal_i + background_i`.
   The best-fit `mu_hat` maximizes the total Poisson log-likelihood `logL(mu)`
   (found via 1-D bounded numerical optimization, restricted to the region
   where all channel means stay positive). The profile
   `-2*Delta logL(mu) = 2*(logL(mu_hat) - logL(mu))` is then scanned, and the
   `+-1 sigma` interval endpoints `mu_lo`, `mu_hi` are the two roots of
   `-2*Delta logL(mu) = 1`, found by bisection (`scipy.optimize.brentq`) on
   either side of `mu_hat`.

## Usage

```bash
./run.sh INPUT_JSON OUTPUT_JSON
```

Example:

```bash
./run.sh /root/data/four_lepton_counts.json /root/results/results.json
```

This writes a JSON file with `logL_b`, `logL_sb`, `test_statistic`,
`p_value`, `significance`, `mu_hat`, `mu_lo`, `mu_hi` (plus some auxiliary
fields), and produces two diagnostic plots under `diagnostics/`:

- `test_statistic_distribution.png`: histogram of the toy test statistics
  under the background-only hypothesis, with the observed `q` marked.
- `mu_scan.png`: the `-2*Delta logL(mu)` profile scan, with `mu_hat` and the
  `+-1 sigma` crossing points marked.

## Files

- `analysis.py` — the full analysis implementation.
- `run.sh` — thin wrapper invoking `analysis.py` with the required
  command-line interface and diagnostic output directory.
- `diagnostics/` — output plots from the run on the provided dataset.

## Result on the provided dataset

Running on `/root/data/four_lepton_counts.json` (channels `4mu`, `2e2mu`,
`4e`; observed `[6, 5, 2]`) gives approximately:

- `test_statistic` (observed `q`): -10.53
- `p_value`: ~2.6e-4 (from 5,000,000 background-only toys)
- `significance`: ~3.5 sigma — reaches the 3-sigma "evidence" level
- `mu_hat`: ~1.62, with `mu_lo` ~1.01 and `mu_hi` ~2.37 (i.e.
  `mu = 1.62 (+0.74/-0.61)`)
